# 🚀 Workforce Attrition Intelligence Platform

An interactive **HR Analytics Dashboard** built using **Python, Streamlit, Plotly, and Machine Learning** to analyze employee attrition and predict high-risk employees.

---

## 📊 Project Overview

Employee attrition is a major challenge for organizations.
This dashboard helps HR teams:

* Analyze employee attrition trends
* Identify departments with high attrition
* Discover key factors influencing employee turnover
* Predict employee attrition risk using Machine Learning

---

## 🧠 Features

✔ Interactive HR Dashboard
✔ Workforce Overview KPIs
✔ Department Attrition Analysis
✔ Job Role Attrition Analysis
✔ Tenure Analysis
✔ Overtime Impact Analysis
✔ Business Travel Analysis
✔ Correlation Heatmap
✔ Feature Importance (ML)
✔ Employee Attrition Risk Prediction
✔ Downloadable HR Risk Report
